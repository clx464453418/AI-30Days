# 换电脑指南

本指南只写项目运行所需的通用步骤，不绑定某台电脑的安装路径。

## 环境

- Windows 电脑
- Python 3.13（本项目曾在 Python 3.13.16、OpenAI SDK 3.24.0 上验证）
- Git
- VS Code（可选）

## 获取项目与依赖

1. 从 GitHub 克隆本仓库，并在 VS Code 中打开仓库根目录。
2. 在你自己的 Python 环境安装依赖：

   ```powershell
   python -m pip install openai
   ```

3. 在 Windows 环境变量中设置 `DEEPSEEK_API_KEY`。不要把密钥写入代码、Markdown 或提交记录；设置后重新打开终端。
4. 从仓库根目录运行，例如：

   ```powershell
   python day03\day03_aiapi.py
   python day07\day07_stream.py
   ```

如果 `python` 命令不可用，请使用本机实际安装的 Python 启动器或解释器路径；不要照抄另一台电脑的绝对路径。

## 安全与本地数据

- `.gitignore` 已排除 `.env`、密钥文件和 `day05/history.json`。
- 不要提交 API Key、个人凭据或聊天存档。
- Ollama 是可选支线；模型文件不包含在仓库中，需要在新电脑单独安装和下载。主线 API 学习不依赖 Ollama。

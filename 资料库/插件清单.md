# DSH 插件清单

最后核对：2026-10-16

本文用于跨电脑迁移时识别需要在 **DeepSeek Harness（DSH）** 里恢复的外置插件。
只记录**安装名、版本、作用与注意事项**，不包含插件包本身、机器专属绝对路径或凭据。

清单来源：在原机器上从 DSH 的 `desktop` profile **实测读出**（`package.json` 的
`dependencies` 与 `dsh.profile.bundles`，以及 `node_modules` 里的实际版本），不是凭记忆。
插件状态会随 DSH 版本变化，换设备后应按安装名重新核验。

## 3. 三个特殊项（换电脑必须单独处理）

### 3.1 桌宠桥是本地 `link:` 依赖
它的依赖写法是 `link:<桌宠程序目录>/.../dsh-pet-bridge`，即**指向本机某个目录**。
换电脑后若桌宠装在别处，必须重新用实际的本地路径添加，否则 DSH 启动会报解析失败。

### 3.2 微信渠道要扫码
`dsh-wechat-plugin` 装完后需在 DSH 的**设置 → 微信**里扫码绑定；绑定状态保存在 DSH 家目录中，
**升级插件不会丢**（但换电脑要重新扫）。首次使用前建议确认权限预设与「是否需要确认」等安全选项。

### 3.3 皮肤必须互斥
同一时间只启用**一套**皮肤；`deep-whale-manager` 负责切换与互斥。若出现"设置按钮不见／侧栏宽度异常／装饰叠在一起"，
说明两套皮肤同时在跑 → 在皮肤管理里点「官方默认」或任一皮肤，再刷新页面。

## 4. 装法（两条路）

1. **界面（推荐）**：DSH →「插件」页 →「添加插件」→ 粘贴 §1 的安装名。
2. **命令行**：`dsh plugin --profile <profile> add <安装名>`
   ⚠️ 桌面端 profile 由应用管理，命令行在某些情况下会被拒绝；桌面版请优先用界面。

## 5. 已知坑（换电脑照着躲）

1. **包名陷阱**：`dshmarket`（插件市场）不是 `dsh-market`；`dsh-wechat-plugin`（本项目用的）不是 `dsh-wechat`
   （后者是另一位作者的同类插件）。
2. **pnpm store 错位**：若把 pnpm 的全局 `storeDir` 改到别处，而 `node_modules` 是用旧 store 装的，
   安装会直接失败并报 `ERR_PNPM_UNEXPECTED_STORE`。**要么别改，要么改完重新链接依赖**（在 profile 里跑一次 `pnpm install`）。
3. **直接调用 `pnpm add` 装插件不算装好**：那样不会把插件登记进 `dsh.profile.bundles`，DSH 启动时不会加载它。
   解决：用 DSH 的安装入口（界面），或卸载后重新用 DSH 的方式安装。
4. **peer 依赖白名单**：部分插件用**枚举式白名单**声明支持的 DSH 版本，DSH 大版本升级后可能被自动停用，
   需要等作者更新或使用官方的版本放行机制。
5. **npm 官方源可能很慢**：安装卡住时，可换用国内镜像源再试。
6. **皮肤"装了但界面没变化"**：皮肤状态写在**多层配置**里，若有一层残留旧值会覆盖另一层；判断是否真正生效，
   要看**最终生效的配置**与界面实际表现，而不是只看某一层配置。
